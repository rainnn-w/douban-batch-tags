# 豆瓣看过-批量标签助手

在豆瓣「看过」页面（`movie.douban.com/people/*/collect`）批量添加 / 移除影片标签的 Tampermonkey（油猴）脚本。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 安装本脚本（二选一）：
   - Greasy Fork：`（发布后补充链接）`
   - 直接打开 [douban-batch-tags.user.js 的 raw 链接](https://raw.githubusercontent.com/rainnn-w/douban-batch-tags/main/douban-batch-tags.user.js)，Tampermonkey 会弹出安装确认

## 功能

- 📋 面板内影片列表勾选（大复选框，点击整行即可选中）
- 🔍 按片名搜索当前列表
- 🏷️ 列表筛选（只影响显示，实时生效）：
  - 只看无标签
  - 按我的评分（1~5 星 / 未评分）
  - 按年份范围（尽力解析，非精确）
  - **按已有标签**：自动汇总全部条目的现有标签（带数量），点击标签胶囊即可筛选，可多选
- 💊 预设标签胶囊：左键选入添加框，右键删除，localStorage 持久化
- 📥 一键加载全部页（每页 25 部，页间 0.8s，最多 40 页，脚本头部 `MAX_PAGES` 可改）
- ▶ 批量提交带进度条，随时可停止，失败项一键重试
- 🟢 可拖拽、可折叠的豆瓣绿悬浮面板

## 使用流程建议

```
加载全部页 → 勾选"只看无标签"（或在"已有标签"框输入想过滤的标签）
→ 全选可见项 → 点预设标签 → 开始处理勾选项
```

## 使用注意

- 脚本会**以你的登录身份**直接修改豆瓣标记
- 首次使用请先勾选 1~2 部测试，确认评分与短评未被误清
- 内置每条 1.5~3 秒随机延迟，请勿自行调小，防止账号风控
- 批量操作前建议先备份豆瓣记录
